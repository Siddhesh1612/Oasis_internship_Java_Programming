# Number Guessing Game

## Project Description

Number Guessing Game is a simple Java project where the computer generates a random number and the user has to guess it.

The program gives hints whether the entered number is higher or lower than the generated number.

---

## Features

- Generates random numbers between 1 to 100
- Takes input from user
- Gives hints:
    - Too High
    - Too Low
    - Correct Guess
- Limited number of attempts
- Multiple rounds available
- Displays final score

---

## Working

1. The computer generates a random number.
2. User enters a guessed number.
3. Program compares both numbers.
4. If guess is correct, score is added.
5. If guess is wrong, hint is displayed.
6. Game continues until attempts are completed.
