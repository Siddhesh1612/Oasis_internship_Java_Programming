# Online Examination System

## Project Description

Online Examination System is a Java based project that allows students to login and attempt an online test.

The system provides multiple choice questions and automatically calculates the final score.

---

## Features

- User Login System
- Update Profile and Password
- Multiple Choice Questions
- Answer Selection
- Auto Submission
- Score Calculation
- Logout Option

---

## Working

1. User enters username and password.
2. Login details are verified.
3. User can update profile information.
4. User starts online examination.
5. MCQ questions are displayed.
6. User selects answers.
7. System automatically submits exam.
8. Final score is displayed.
